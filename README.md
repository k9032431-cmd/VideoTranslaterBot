# 🎬 VideoTranslaterBot

Телеграм-бот, который переводит видео и фильмы на другой язык: субтитрами, закадровой озвучкой или и тем и другим.

## Как пользоваться

1. **/start** → выбрать язык бота (🇷🇺 / 🇬🇧 / 🇺🇦). Позже язык меняется кнопкой **🌐 Язык бота** в меню или командой /language.
2. **🎬 Перевести видео** → отправить видео (как видео или как файл).
3. Кнопками выбрать, **на каком языке видео** (или «🤖 Определить автоматически»).
4. Кнопками выбрать, **на какой язык перевести**.
5. Выбрать формат: **📝 Субтитры**, **🎙 Озвучка** или **🎙📝 Озвучка + субтитры**.
6. Проверить сводку и нажать **✅ Начать перевод**.

Бот показывает прогресс по этапам и присылает готовое видео и файл субтитров `.srt`. На каждом шаге есть кнопки «⬅️ Назад» и «❌ Отмена», а идущий перевод можно отменить.

Языки видео: русский, английский, украинский, немецкий, французский, испанский, итальянский, португальский, польский, турецкий, казахский, узбекский, арабский, китайский, японский, корейский.

## Как это работает

```
видео ─ffmpeg→ звук ─Whisper→ текст с таймкодами ─GPT→ перевод ─┬→ субтитры .srt ─ffmpeg→ вшиваются в видео
                                                                └→ TTS → дорожка озвучки ─ffmpeg→ микс с оригиналом
```

Что сделано для точности:

- **Распознавание.** Длинное аудио режется на куски по ~10 минут **в паузах**, а не посреди слова. В каждый следующий кусок передаётся конец предыдущего текста, чтобы имена и стиль не «плыли». Фразы, которые Whisper «слышит» в тишине или музыке, и зацикленные повторы отбрасываются.
- **Перевод.** Строки переводятся пачками по 40, каждой пачке передаются предыдущие строки для контекста (род, «ты/вы», термины). Модель просят переводить как профессиональный переводчик фильмов, а не дословно. Ответ проверяется строго: каждая строка должна быть переведена, ни одна не потеряна. Если проверка не прошла, запрос повторяется, а потом пачка делится пополам.
- **Субтитры.** Не больше двух строк по 42 символа (для китайского, японского и корейского по 16) и не дольше 7 секунд на экране. Длинные фразы делятся по знакам препинания.
- **Озвучка.** Для неё перевод делается с учётом длительности каждой фразы. Каждая фраза ставится точно на свой таймкод. Если не влезает, она немного ускоряется (максимум в 1.35 раза, чтобы звучало естественно). Оригинал остаётся тихим фоном, как в классическом закадровом переводе.

## Установка на сервер одной командой

Подойдёт любой VPS с **Ubuntu 22.04 / 24.04** или **Debian 12**. Заранее нужны:

- токен бота: создать бота у [@BotFather](https://t.me/BotFather);
- ключ OpenAI: <https://platform.openai.com/api-keys>;
- свой Telegram id (по желанию): узнать у [@userinfobot](https://t.me/userinfobot).

Зайти на сервер под root и выполнить:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/k9032431-cmd/VideoTranslaterBot/main/install.sh)
```

Скрипт сам установит ffmpeg, Python и шрифты, скачает бота, спросит токен, ключ и id (и сразу проверит, что они рабочие), а потом запустит бота как службу. Бот запускается вместе с сервером и поднимается сам, если упадёт.

## Обновление одной командой

```bash
vtbot update
```

Скачивает новую версию, ставит новые зависимости и перезапускает бота. Настройки (`.env`) и данные сохраняются, а настройки, которые появились в новой версии, дописываются в `.env` автоматически. Если новая версия не запустилась, скрипт сам возвращает предыдущую.

## Управление

| Команда | Что делает |
|---|---|
| `vtbot update` | обновить до новой версии |
| `vtbot status` | версия и состояние |
| `vtbot logs` | логи в реальном времени (выход — Ctrl+C) |
| `vtbot restart` / `stop` / `start` | перезапустить / остановить / запустить |
| `vtbot config` | поменять токен, ключ OpenAI, список пользователей |
| `vtbot bigfiles` | включить файлы до 2 ГБ (см. ниже) |
| `vtbot uninstall` | удалить бота |

Бот ставится в `/opt/videotranslaterbot`, настройки лежат в `/opt/videotranslaterbot/.env`. Остальные параметры (голос, модели, лимиты) можно поменять там, после чего выполнить `vtbot restart`.

### Большие файлы (фильмы до 2 ГБ)

Обычный Telegram Bot API даёт боту скачивать файлы **до 20 МБ** и отправлять **до 50 МБ**. Для фильмов нужен свой локальный сервер Bot API:

1. Получить `api_id` и `api_hash` на <https://my.telegram.org> → API development tools.
2. Выполнить `vtbot bigfiles` и ввести их. Скрипт поставит Docker, запустит сервер и переключит на него бота.

Если готовое видео всё равно не помещается в лимит, бот пришлёт отдельно дорожку озвучки и субтитры.

## Другие способы запуска

**Docker Compose:** `cp .env.example .env`, заполнить `.env`, затем `docker compose up -d --build`. Для файлов до 2 ГБ: заполнить `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`, раскомментировать `TELEGRAM_API_URL` и запустить `docker compose --profile bigfiles up -d --build`.

**Вручную:** нужны Python 3.10–3.14 и ffmpeg.

```bash
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить
python -m bot
```

## Сколько это стоит (OpenAI, примерно)

| Этап | Цена |
|---|---|
| Распознавание (whisper-1) | ~$0.006 за минуту видео |
| Перевод (GPT) | центы за фильм |
| Озвучка (gpt-4o-mini-tts) | ~$0.015 за минуту речи |

Фильм на 1.5 часа: субтитры — около **$0.6**, с озвучкой — около **$2**. Модели меняются в `.env`.

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `ALLOWED_USER_IDS` | все | кто может пользоваться ботом |
| `TRANSLATE_MODEL` | `gpt-5.4` | модель перевода |
| `TTS_VOICE` | `onyx` | голос озвучки |
| `MAX_VIDEO_MINUTES` | `180` | максимальная длительность видео |
| `MAX_CONCURRENT_JOBS` | `2` | сколько видео обрабатывается одновременно, остальные ждут в очереди |
| `ORIGINAL_VOLUME` | `0.15` | громкость оригинала под озвучкой |

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты проверяют логику (субтитры, тайминг озвучки, перевод с повторами), весь диалог с кнопками через aiogram с подменённым Telegram и полный прогон ffmpeg-конвейера на сгенерированном видео с подменённым OpenAI.

## Структура

```
install.sh           установка / обновление / управление (команда vtbot)
bot/
  __main__.py        запуск
  config.py          настройки из .env
  i18n.py            тексты интерфейса (ru / en / uk)
  languages.py       языки видео
  keyboards.py       кнопки
  middlewares.py     доступ и язык пользователя
  storage.py         SQLite: язык интерфейса каждого пользователя
  jobs.py            фоновые задачи, очередь, статус, отправка результата
  handlers/          диалог
  pipeline/          media (ffmpeg) → transcribe → translate → subtitles / dubbing → render
```
